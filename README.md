# 🚗 QuickParking – Smart Parking Management System

QuickParking is a cross-platform Smart Parking Management System developed using Flutter and Dart, with Supabase and PostgreSQL for backend and database management. It helps customers find available parking spaces, book slots, manage reservations, and verify bookings through QR codes.

## 📌 Project Overview

QuickParking provides a convenient and efficient platform for managing parking operations. It includes separate Customer and Admin modules to simplify parking reservations and administrative tasks.

## ✨ Features

### 👤 Customer Module
- User Registration and Login
- Forgot Password and Password Reset
- Customer Dashboard
- Search Parking Locations
- View Parking Slot Availability
- Book Parking Slots
- Automatic Parking Charge Calculation
- Payment Options (UPI and Pay at Parking)
- QR Code Booking Verification
- Booking History
- Notifications
- Profile Management

### 🛠️ Admin Module
- Admin Login and Profile Management
- Dashboard
- Customer Management
- Parking Location Management
- Parking Slot Management
- Booking Management
- Payment Management
- QR Code Verification
- Daily, Monthly, and Yearly Reports
- PDF and XML Report Export
- Admin Settings

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/QuickParking-Smart-Parking-Management-System.git
```

### 2. Open the Project

```bash
cd QuickParking-Smart-Parking-Management-System
```

### 3. Install Dependencies

```bash
flutter pub get
```

### 4. Configure Supabase

Add your Supabase project URL and publishable/anon key using your project's configuration method.

Do not upload private API keys, service-role keys, database passwords, or other secrets to GitHub.

### 5. Run the Application

```bash
flutter run
```

## 🗄️ Database

QuickParking uses Supabase with PostgreSQL to store and manage customer information, administrator details, parking locations, parking slots, bookings, payments, and notifications.

## 🎯 Project Objective

The main objective of QuickParking is to provide a simple, reliable, and efficient parking management solution that reduces manual parking operations and improves the customer parking experience.
